01已完成

Automation · Data & BI

月報表整合與自動化優化

整合多元資料來源並建立 Power BI 自動更新流程，降低月初報表製作的重複性人工作業。

我的角色
報表製作者及流程優化執行者
使用工具
Power BI · SQL Server · SharePoint · Excel · AI 協作

專案背景

既有月報表的資料來源分散，包含地端檔案、系統資料及人工維護的 Excel，導致每月初需投入大量時間進行資料蒐集、整理與更新。

問題與需求

資料來源多元且缺乏一致的整合方式；每月需重複整理與更新，也增加資料定義確認及人工作業成本。

需求分析

整合不同資料來源、釐清指標與資料定義，並建立可定期自動更新的報表流程。

解決方法

整理既有流程 → 釐清欄位定義、統計邏輯與資料區間 → 將 SharePoint、SQL Server 等資料整合至 Power BI → 設定排程更新 → 讓 Excel 串接 Power BI 資料並一鍵更新。

專案成果

完成主要資料來源整合與自動更新流程，減少月報表製作中的重複性人工操作。

後續優化

規劃以 Python 建立 RPA 流程，自動產製報表並於指定時間寄送或通知。

02建置中

Cloud Migration · Data & BI

月報表地端資料源雲端移轉

配合組織資料上雲，重新串接 Power BI 與 Excel 報表資料源，並執行移轉後的資料驗證。

我的角色
雲端資料驗證及報表重建執行者
使用工具
Power BI · Google BigQuery · SharePoint · Excel · AI 協作

專案背景

原有月報表的部分資料來源位於地端環境。因應組織資料上雲，相關資料陸續移轉至 Google BigQuery，既有報表也需重新建立資料連線與驗證機制。

問題與需求

既有 Power BI 與 Excel 報表需重新串接資料，並確認移轉前後的欄位、定義及報表結果一致。

需求分析

重新設計資料來源連線，完成報表重串與資料驗證，同時兼顧後續接手者的維護便利性。

解決方法

盤點地端資料來源 → 比對 BigQuery 新資料表與定義 → 重建 Power BI、Excel 資料連線 → 驗證前後結果。以重新建置為主要方案，避免過多虛擬表或過渡性嫁接架構增加維護複雜度。

專案成果

已完成部分資料來源的重新串接與驗證，其餘資料配合上雲進度持續建置中。

後續優化

待資料來源穩定後，規劃以 Python 建立 RPA，自動產製並定時寄送報表。

03已完成

Data & BI

部門成本分析 Power BI 儀表板

依據高階主管需求，建立支援去年同期及上月比較的成本分析儀表板。

我的角色
需求訪談者及 Power BI 報表製作者
使用工具
Power BI · SharePoint · Excel · AI 協作

專案背景

部門高階主管每月需要分析各部門成本，包含去年同期與上月比較。既有作業主要透過 Excel 樞紐分析，資料整理與查找較不便利。

問題與需求

需要一致且能快速瀏覽的視覺化介面，協助各部門主管掌握成本變化並對焦異常項目。

需求分析

依主管分析情境，建立成本分析 Power BI 儀表板，支援去年同期及上月比較。

解決方法

訪談使用者 → 確認比較邏輯 → 將所需資料整合至 SharePoint → 由 Power BI 串接 SharePoint 中的 Excel → 設計適合主管閱讀的分析畫面與篩選功能。

專案成果

完成成本分析 Power BI 儀表板建置，並推廣供相關主管使用。

後續優化

評估導入 AI 對話與摘要功能，讓使用者直接詢問報表內容，或在進入報表時先取得重點摘要。

04持續進行

System Optimization · Project Management

公司 e-Service 系統優化與營運維護

以副 PM 角色協助整合使用者需求、外包商溝通與迭代排程，持續推動系統優化。

我的角色
副 PM
使用工具
OtisPM

專案背景

公司 e-Service 系統在既有操作流程與使用體驗上存在多項改善需求，因此由新的專案團隊接手，重新盤點問題並逐步優化。

問題與需求

需求涉及不同單位、系統限制與開發資源，需要在使用者期待、技術可行性與開發排程之間取得平衡。

需求分析與流程

使用者訪談與需求蒐集 → 彙整分類並釐清情境 → 盤點限制、依賴關係與難點 → 與外包商討論可行性及排程 → 階段成果與使用者及主管對焦 → 依回饋調整優先順序。

我的角色

協助需求整合、跨單位溝通、進度追蹤與階段成果對焦。

工作方法

透過持續溝通、即時回應與彈性調整，協助使用者、主管及外包商建立一致的需求理解。

專案成果

專案持續進行中，相關需求依優先順序及開發排程逐步推動。

後續優化

持續完善需求治理、優先順序管理、驗收標準及階段成果追蹤方式。

05已完成

Knowledge Sharing · Data & BI

跨部門 Power BI 推廣、課程與社群支援

透過初學者課程、可重複觀看的教學內容、社群答疑及跨部門協作，協助組織建立 Power BI 應用基礎。

我的角色
講師、社群支援者及報表製作者
使用工具
Power BI · PowerPoint · Google BigQuery · SharePoint · Excel

專案背景

不同部門具有 Power BI 學習及報表製作需求，但缺乏統一的入門資源與問題解答管道；部分複雜報表也需要跨部門合作。

問題與需求

提供適合零基礎使用者的教學、可重複觀看的課程內容、持續提問平台及跨部門報表製作支援。

需求分析

同時規劃 Power BI 入門教學、課程錄影、問題交流社群，以及較複雜報表的跨部門協作。

解決方法

確認學員背景 → 以零基礎使用者設計教材 → 透過 Teams 進行線上教學及錄影 → 建立交流社群 → 追蹤並協助回答實作問題 → 跨部門完成較複雜報表。

專案成果

完成 Power BI 入門課程、課程錄影、社群建立及相關報表製作支援。

經驗與後續優化

首次講授仍有提升授課節奏與表達穩定度的空間。曾規劃課程專用 AI Agent，但因公司政策限制未正式發布；後續可在合規與權限允許的環境重新評估。
